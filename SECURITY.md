# 🔐 Security Policy – Rahul Roy Portfolio

## 📦 Supported Versions

This portfolio is a continuously updated project.
Only the latest deployed version is actively maintained and supported.

| Version        | Supported |
| -------------- | --------- |
| Latest         | ✅ Yes     |
| Older versions | ❌ No      |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### 📧 Contact

* Email: [rr6216009@gmail.com](mailto:rr6216009@gmail.com)
* Subject: **[Security Issue] Portfolio Vulnerability Report**

---

## 📋 What to Include

To help resolve the issue quickly, please include:

* Description of the vulnerability
* Steps to reproduce
* Possible impact
* Screenshots or proof (if applicable)

---

## ⏱ Response Time

* Initial response: **within 24–48 hours**
* Fix timeline: depends on severity (usually within a few days)

---

## 🔒 Responsible Disclosure

Please:

* Do NOT publicly disclose the issue before it is fixed
* Do NOT open a public GitHub issue for security bugs

This helps protect users and maintain project integrity.

---

## ⚠️ Scope

This policy applies to:

* Portfolio website
* Source code (GitHub repository)
* Deployed version (Vercel)

---

## 💡 Final Note

Security is taken seriously.
Even though this is a portfolio project, it follows real-world best practices.

Thank you for helping make this project safer 🙌
