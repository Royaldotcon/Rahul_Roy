## 🛠 Getting Started

Clone the project:

```bash
git clone https://github.com/royaldotcon/Rahul_Roy.git
cd your-repo
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
