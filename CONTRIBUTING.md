# Contributing to Rahul Roy Portfolio

First off, thank you for your interest in contributing! ❤️
This portfolio is not just a personal site — it’s a growing open project showcasing modern web development, design, and performance engineering.

---

## 📜 Code of Conduct

By participating, you agree to follow the Code of Conduct.

Please be respectful, professional, and collaborative in all interactions.

---

## 🙋‍♂️ Ways to Contribute

Even though this is a personal portfolio, contributions are welcome in areas like:

* 🐛 Bug fixes
* ✨ UI/UX improvements
* ⚡ Performance optimizations
* 📱 Responsiveness enhancements
* 📖 Documentation improvements
* 🌐 Accessibility improvements

---

## 🐞 Reporting Bugs

Before submitting a bug:

* Make sure you're using the latest version
* Check if the issue already exists

### To report a bug:

1. Open a GitHub Issue
2. Clearly describe:

   * Expected behavior
   * Actual behavior
   * Steps to reproduce
3. Add screenshots or screen recordings if possible

---

## 💡 Suggesting Features

Have an idea? Awesome.

When suggesting a feature:

* Explain the idea clearly
* Describe why it’s useful
* Add examples or references if possible

---

## 🛠 How to Contribute Code

1. Fork the repository
2. Create a new branch:

   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes
4. Commit with a clear message:

   ```bash
   git commit -m "feat: add smooth scroll animation"
   ```
5. Push and open a Pull Request

---

## ✍️ Commit Message Guidelines

Use clean and meaningful commit messages:

* `feat:` → new feature
* `fix:` → bug fix
* `refactor:` → code improvement
* `docs:` → documentation
* `style:` → UI changes

Example:

```bash
feat: improve hero animation performance
```
